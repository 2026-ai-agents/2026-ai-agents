> 원안 5.7절. Day 1의 마지막 세션입니다.  
> 시연 중심의 짧은 세션이며, 시연 구성은 확정되는 대로 이 문서에 채워집니다.

- **핵심 문장**: 도구를 손으로 정의하는 대신, 표준 프로토콜로 주고받는다

## 무엇이 달라지는가

오늘 하루 종일 도구는 우리가 손으로 정의했습니다. 스키마를 쓰고, 실행 관문을
만들고, 결과를 되먹였습니다. Model Context Protocol, 곧 [[mcp|MCP]]는 그 도구를
표준 프로토콜로 주고받는 방식입니다.

- 도구 제공자가 MCP 서버를 열면, 클라이언트는 그 도구 목록을 프로토콜로
  받아옵니다
- 우리 코드에는 도구별 구현이 없어도 됩니다. 연결만 하면 도구 목록이 늘어납니다
- 도구 정의(스키마·설명)의 모양은 오늘 본 것과 같습니다. 표준화된 것은 껍데기가
  아니라 주고받는 방법입니다

## 시연

공개 MCP 서버의 도구를 여행 에이전트에 연결해, 코드 수정 없이 도구 목록이
늘어나는 것을 관찰합니다.

- 연결 전: `agent/tools.py`의 3종(검색·이동시간·예산)뿐
- 연결 후: MCP 서버가 제공하는 도구들이 같은 목록에 나란히 등장
- 에이전트 루프는 어느 쪽 도구인지 구분하지 않고 같은 방식으로 부릅니다

## Day 3 예고: 역방향

오늘은 도구를 **가져오는** 쪽이었다면, Day 3에서는 우리가 만든 에이전트를
MCP 서버로 만들어 **내어주는** 쪽을 봅니다. food-rag-agent의 식단 추천 도구를
개인 Claude 계정에 커스텀 커넥터로 등록해, 폰의 Claude 앱에서 동작하는
순간까지가 시연입니다.
