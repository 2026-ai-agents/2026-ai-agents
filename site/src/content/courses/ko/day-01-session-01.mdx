## 이 과정의 규칙

수업 중 실습·과제는 없습니다. 코드는 전부 완성본으로 제공되고, 세션은 강사가
실행·해설하는 시연과 코드 리딩으로 진행합니다. 재현은 각자의 속도로 하면
됩니다. 같은 명령이 같은 결과를 냅니다.

- 모든 소스는 GitHub 조직 [2026-ai-agents](https://github.com/2026-ai-agents)에 공개
- 저장소 하나가 에이전트 하나이자 완결된 제품
- 모든 저장소는 `docker compose` 기반. 로컬 Python 환경이 필요 없습니다

## 릴리즈 사다리 사용법

[[release-ladder|릴리즈 사다리]]는 이 과정의 진행 방식 그 자체입니다.
세션 진행이 태그를 오르는 것과 1:1로 대응합니다.

```bash
git checkout v0.2 && docker compose up --build -d   # 그 시점의 코드로 그 시점의 동작
git diff v0.2 v0.3                                  # 이번 feature가 코드로는 무엇이었나
docker compose exec lab pytest                      # 어느 태그에서든 그 시점의 테스트가 통과
```

Day 1의 사다리는 다섯 단입니다. 2026-08-14 기준으로 각 단에서 유닛 테스트가
전부 통과하는 것을 확인해 두었습니다.

| 릴리즈 | 상태 | 테스트 |
| --- | --- | --- |
| v0.1 | 예제 51종 + 에이전트 뼈대 (도구 없음) | 5개 통과 |
| v0.2 | 도구 장착: 예산 계산 도구가 스키마로 실림 | 16개 통과 |
| v0.3 | [[react\|ReAct]] 루프 완성: 여행 플래너가 처음 동작 | 17개 통과 |
| v0.4 | 고급 루프: [[reflexion\|Reflexion]] 재시도 장착 | 21개 통과 |
| v1.0 | [[harness\|하네스]] 완성: 인젝션 방어 + budget guard | 33개 통과 |

## 랩 기동과 환경 점검

```bash
git clone https://github.com/2026-ai-agents/day-01.git
cd day-01
cp .env.sample .env        # 편집기로 열어 키 채우기 (셋 중 하나면 됨)
docker compose up --build -d
docker compose exec lab python check_env.py
```

`check_env.py`가 확인하는 것은 세 가지입니다. 키 유효성(채워진 키로 실제 호출
1회), 사용 가능한 모델, 컨테이너 내 패키지 버전. 이 랩의 기준 버전은
다음과 같습니다.

```text
=== 패키지 버전 ===
  python   3.13.15
  litellm  1.96.2
  pydantic 2.13.4
  pytest   8.4.2
```

키가 하나도 없으면 해결 방법을 안내하고 종료 코드 1로 끝납니다. 잘 안 되면
[사전 준비 가이드](/article/prep-guide/)의 "잘 안 될 때" 표를 먼저 확인하세요.

## 예제 실행 방법

예제는 전부 `docker compose exec`로 실행합니다. 각 파일 상단 docstring에
"무엇을 보는가"와 실행 명령이 있습니다.

```bash
docker compose exec lab python examples/01_api/01_hello_completion.py
```

- 예제 51종을 전부 수업에서 실행합니다. 세션 문서에 실행 결과가 함께 실려
  있어, 재현할 때 자기 출력과 대조할 수 있습니다
- 키 없이도 도는 예제가 있습니다: 토큰 세기, 단가표, 스키마 생성, 경로 감금,
  출력 필터, 비용 추정, budget guard, 트레이스 로그
- 유닛 테스트는 키·네트워크 없이 돕니다: `docker compose exec lab pytest`

## 비용은 얼마나 드나

[사전 준비 가이드](/article/prep-guide/)에서 소액($5\~$10) 충전을 권장했습니다.
그 돈이 어디에 얼마나 쓰이는지 감을 잡아 둡니다. 아래는 이 랩의 실제 코드로
잰 2026-08-14 실측입니다.

| 하는 일 | 비용 |
| --- | --- |
| `check_env.py` 1회 (3사 각 1콜) | $0.0001 미만 |
| 예제 하나 실행 (호출 1\~5회) | $0.001 \~ $0.01 수준 |
| 여행 플래너 풀런 1회 (루프 + 도구 3종) | $0.003 \~ $0.010 |
| 루프가 8스텝을 다 쓰는 최악 시나리오 | $0.007 \~ $0.033 |

- 예제 51종을 전부 따라 돌리고 에이전트를 여러 번 실행해도 하루 $1
  안쪽입니다. $5 충전이면 3일 과정 전체에 충분합니다
- 유닛 테스트(`pytest`)는 LLM을 부르지 않으므로 0원입니다
- 키 없이 도는 예제(토큰 세기·단가표·경로 감금·budget guard 등)도 0원입니다
- 이 랩의 기본 모델 3종은 전부 각 사의 저가 티어입니다. 단, 프로바이더마다
  가격 하한이 달라서 Anthropic이 상대적으로 비쌉니다. 셋 중 하나만 충전한다면
  이 표가 선택 기준이 됩니다

비용을 직접 계산하는 법은 [2세션](/course/day-01-session-02/)에서, 모델별
단가표는 [3세션](/course/day-01-session-03/)에서, 누적 비용에 상한을 거는
[[budget-guard|budget guard]]는 [7세션](/course/day-01-session-07/)에서
다룹니다. 호출 한 번은 티끌이지만 에이전트는 루프라서, 비용 감각은 첫날부터
장비처럼 챙깁니다.
