## 저장소 하나 = 에이전트 하나
::sub[Day 1은 실습 랩, Day 2부터는 독립된 제품]

```bash
git clone https://github.com/2026-ai-agents/day-01.git
cd day-01
cp .env.sample .env
docker compose up --build -d
docker compose exec lab python check_env.py
```

- 공통인 것은 시작 명령뿐
