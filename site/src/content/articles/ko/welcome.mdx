쌓입니다.

- **[슬라이드](/slides/)**: 수업에서 쓰는 발표 자료. 브라우저에서 바로 넘겨볼

- **[용어집](/glossary/)**: 본문 곳곳에 링크되는 용어들의 한 줄 정의 모음

## 자료와 코드는 따로 있습니다

이 사이트는 **강의 자료**만 담습니다. 실행되는 코드는 GitHub 조직
[2026-ai-agents](https://github.com/2026-ai-agents)의 에이전트별 저장소에
있습니다. 저장소 하나가 에이전트 하나이자 완결된 제품입니다.

공통인 것은 시작 명령뿐입니다.

```bash
git clone <저장소 주소>
cd <저장소>
cp .env.sample .env
docker compose up --build
```

각 저장소의 README가 구조·시나리오·재현 방법을 안내합니다. 전체 목록은
[소개](/about/) 페이지에 있습니다.
